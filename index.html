Modelos de servicio

IaaS

Infraestructura virtual: servidores, red y almacenamiento.

Ej.: AWS EC2, Compute Engine

PaaS

Plataforma lista para desplegar código sin gestionar servidores.

Ej.: Vercel, Heroku, App Engine

SaaS

Software terminado que se usa desde el navegador.

Ej.: Google Drive, Microsoft 365
